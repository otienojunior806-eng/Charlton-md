📖 General Deployment Steps

Fork the Repository

Click the fork button to create your own copy of the repository on GitHub.

Fork URL: github.com/otienojunior806-eng/Charlton-md/fork

Get Your Session Code

Generate a pairing code using the pairing tool:

Generate Pairing Code →

Configure Environment Variables

Set up required environment variables on your hosting platform:

SESSION=your_pairing_code_here OWNER_NUMBER=your_phone_number BOTNAME=CHARLTON-MD OWNER_NAME=Your_Name PREFIX=.

Deploy

Click the deploy button for your chosen platform and follow the prompts.

Verify

Once deployed, scan the QR code with your WhatsApp account to authenticate the bot.
